# BOS staging implementation plan

Approved by Firaz: separate staging branch and app, preserving live BOS.

- [x] Create sibling staging worktree from verified pilot source 1899bfb.
- [x] Add packaged channel identity and early Electron path isolation.
- [x] Separate server, webhook, relay and companion ports, state and protocols; disable staging updater and legacy migration.
- [x] Add isolation regression tests and package a separate signed app.
- [x] Independently review runtime boundaries; verify simultaneous live/staging health without live mutations.

Desktop is the first deliverable. Mobile staging identities follow separately; no other users are updated. Never copy live credentials, chats or tasks. Staging is separate application state, not an OS sandbox: user-authorized tools still have their normal OS access.
